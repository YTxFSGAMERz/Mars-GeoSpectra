# Documentation and Demo
## Goal
Make the project understandable to a technical judge in minutes and demonstrable in under five minutes.
## Required docs
`README.md`, `docs/data-catalog.md`, `docs/methodology.md`, `docs/architecture.md`, `docs/deployment.md`, and `docs/implementation-status.md`.
## Demo storyline
Mars globe → Jezero → layers → target → candidate route → route metrics/science evidence → grounded AI explanation → mission replay → provenance/methodology.
## Language
Prefer “prototype route suitability” over “safe route”, “archived observation” over “live weather” when appropriate, and evidence-qualified mineralogical wording.
## Submission readiness
Include accurate NASA/source attribution for selected products and clearly identify derived/demo data.
